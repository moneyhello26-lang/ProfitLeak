# ProfitLeak AI — запуск с нуля и выступление

Инструкция для Windows 10/11 и готовой папки `ProfitLeak_Presentation`.
Приложение работает на компьютере с SQLite. Docker, Node.js, PostgreSQL,
Render, Neon и ключи LLM для демонстрации не нужны.

## 1. Перенос на другой компьютер

1. Скопируйте `ProfitLeak_Presentation.zip` на другой компьютер.
2. Нажмите правой кнопкой по архиву → **Извлечь всё**.
3. Распакуйте, например, в `C:\ProfitLeak`. Откройте папку, в которой лежат
   `1_INSTALL.cmd`, `2_START.cmd` и этот `README.md`.
4. Устанавливайте и запускайте приложение из распакованной папки.

В комплект входят готовое приложение, PDF и PowerPoint в `presentation/`,
а также демонстрационные CSV в `demo_data/`. Рабочие базы, пароли и API-ключи
в архив не входят. При первом запуске создаётся новая пустая база.

## 2. Установка Python

1. Установите **Python 3.11 или новее** с [официального сайта Python](https://www.python.org/downloads/windows/).
2. В установщике включите **Add python.exe to PATH**, затем завершите установку.
3. Если терминал был открыт до установки Python, закройте его и откройте заново.

Python устанавливается один раз. Остальные библиотеки установит следующий шаг.

## 3. Первая установка приложения

Подключите компьютер к интернету и дважды щёлкните **`1_INSTALL.cmd`**.

Скрипт создаст собственную среду `backend/.venv` и скачает библиотеки приложения.
Дождитесь сообщения **Installation complete**. Установка может занять несколько минут.
После этого нажмите любую клавишу, чтобы закрыть окно.

Альтернатива через PowerShell из папки приложения:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install-local.ps1
```

Если установлено несколько версий Python, можно указать нужную явно:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install-local.ps1 -Python "C:\Path\To\python.exe"
```

Замените пример пути на путь к вашему `python.exe`.
Среду `.venv` с другого компьютера переносить не нужно.

## 4. Обычный запуск

1. Дважды щёлкните **`2_START.cmd`**.
2. Дождитесь строки **Uvicorn running on http://127.0.0.1:5173**.
3. Откройте в браузере **http://127.0.0.1:5173**.
4. Оставьте окно сервера открытым на время работы.

После первой установки интернет для обычной работы не нужен.
Повторно запускать установку перед каждым выступлением не требуется.

Остановка: нажмите **Ctrl+C** в окне сервера. При следующем запуске данные сохранятся.
Приложение доступно только на том компьютере, где оно запущено.

## 5. Первый вход и демонстрационный бизнес

1. Откройте **Регистрация** и создайте аккаунт: имя, email и пароль от 10 символов.
   Email используется как локальный логин, подтверждать его письмом не требуется.
2. Нажмите **Открыть демо-бизнес**. Это синтетический пример кафе в Таразе:
   3 товара и 90 дней операций.
3. На странице обзора проверьте период **04.07.2026–01.10.2026**.
4. Контрольные показатели за все 90 дней:

| Показатель | Значение |
| --- | ---: |
| Выручка | 5 454 000 ₸ |
| Себестоимость | 2 475 000 ₸ |
| Валовая прибыль | 2 979 000 ₸ |
| Операционные расходы | 736 500 ₸ |
| Операционная прибыль | 2 242 500 ₸ |
| Валовая маржа | 54,62% |

Повторное открытие этого демо не дублирует данные.

Для демонстрации ручного импорта создайте **другой бизнес** в разделе **Мой бизнес**.
Загрузите файлы из `demo_data/`, выбирая соответствующий тип: товары, продажи, расходы.
Для каждого файла нажмите **Проверить файл**, затем подтвердите импорт.
Встроенное демо уже содержит эти операции, повторно импортировать их в него не требуется.

## 6. Сценарий выступления на 5–7 минут

1. **Обзор и товары.** Покажите выручку, операционную прибыль и прибыльность позиций.
2. **Детектор проблем.** Выберите все 90 дней и нажмите **Запустить анализ**.
   Появятся три сигнала: рост расходов на упаковку, падение маржи кофе и возможный дубликат расхода.
3. **Доказательства.** Откройте упаковку: 30 000 и 46 500 ₸, рост 55%.
   Покажите формулу, исходные строки, статус проверки и заметку команды.
   Сценарная оценка не означает подтверждённую экономию.
4. **Сравнение периодов.** Оставьте последние 30 дней и предыдущий период той же длины.
   Выручка одинакова: 1 818 000 ₸. Операционная прибыль снизилась
   с 865 500 до 511 500 ₸, на 40,90%. Покажите переключатель **За день**.
5. **Прогнозирование.** Горизонт 30 дней, продажи **+10%**, расходы **−5%**.
   Нажмите **Рассчитать сценарий**. Операционная прибыль сценария — **601 125 ₸**,
   базовая — **511 500 ₸**. Это расчёт на 02.10–31.10.2026 по демо-истории,
   а не обещание результата реального бизнеса.
6. **RU / ҚАЗ и PDF.** Переключите язык и скачайте отчёт кнопкой на странице обзора.
7. **Советник и роли.** Покажите локальное объяснение сигналов. В разделе
   **Аккаунт и команда** объясните роли владельца, аналитика и наблюдателя.

Советник в этом запуске использует локальные шаблоны и не расходует API-токены.
Внешняя LLM отключена. Прогноз рассчитывается отдельно от советника:
он использует средние по дням недели за последние 28–30 дней и не моделирует праздники и тренд.

Для показа слайдов откройте PDF из `presentation/`.
Для редактирования используйте PowerPoint из той же папки.

## 7. Данные и резервная копия

База приложения: **`backend/profitleak.db`**. Она появится автоматически после первого запуска.
В ней находятся локальные аккаунты, бизнесы, импорты и результаты анализа.

Для простой резервной копии остановите сервер через Ctrl+C и скопируйте
`backend/profitleak.db` в отдельную папку. Для переноса своих данных на другой
компьютер используйте эту копию после остановки обоих экземпляров приложения.
Сначала сохраните отдельную копию базы компьютера-получателя, если она уже существует.
При переносе базы используются существующие аккаунты и пароли из этой базы.

Согласованная копия работающей базы через утилиту, из корня приложения:

```powershell
New-Item -ItemType Directory -Force backups | Out-Null
backend/.venv/Scripts/python.exe backend/scripts/sqlite_snapshot.py backup backend/profitleak.db backups/my-backup.db
```

Имя файла копии должно быть новым. Утилита не перезаписывает существующую копию.

## 8. Если не запускается

**Python не найден или открывается Microsoft Store.** Установите Python с официального
сайта, включите добавление в PATH и заново запустите `1_INSTALL.cmd`.

**Установка библиотек завершилась ошибкой.** Проверьте интернет и повторите
`1_INSTALL.cmd`. Сообщение Installation complete должно появиться без красной ошибки.

**Нет backend/.venv.** Сначала выполните установку через `1_INSTALL.cmd`.

**Порт 5173 занят.** Закройте предыдущий сервер или запустите на другом порту:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start-local.ps1 -Port 8017
```

Затем откройте **http://127.0.0.1:8017**.

**Браузер не открывает сайт.** Проверьте, что окно сервера открыто и в нём есть
строка Uvicorn running. Используйте адрес с `http://`, указанный в этом окне.

**Показатели отличаются от презентации.** Выберите демо-кафе и правильный период.
Для обзора нужны все 90 дней, для сравнения — два соседних периода по 30 дней.

# Реалистичные синтетические данные ProfitLeak

Три разных предприятия, 2026-01-01–2026-10-14, KZT. Все данные придуманы моделью и генератором, не получены от реального бизнеса и не являются рыночной статистикой. Цены, спрос и расходы — сценарные предположения, а не подтверждённые средние по Казахстану.

Внутри каждой папки: products.csv, sales.csv, expenses.csv. Сначала импортируйте товары, затем продажи и расходы в отдельный бизнес. CSV имеет UTF-8 BOM и разделитель-запятую. Если доступны XLSX, они содержат те же записи: выбирайте один формат для каждого типа.

Продажи агрегированы по дню, товару и фактической цене, это не отдельные чеки. Есть скидки, возвраты, весовые товары, периоды отсутствия товара, сезонный ассортимент и разные цены/себестоимость. Расходы включают аренду, оплату труда, упаковку, комиссии, доставку, рекламу, списания и ремонт. Себестоимость проданных товаров уже находится в продажах: закупки запасов повторно в расходы не включены. Списания касаются только непроданных остатков.

Расходы и продажи датированы датой операции, без начисления и полного бухгалтерского учёта. Октябрь неполный, по 14.10.2026: его нельзя напрямую сравнивать с полным месяцем. Деньги положительные: return уменьшает продажи и себестоимость, refund уменьшает расходы. Себестоимость заполнена полностью, чтобы графики прибыли оставались доступны. Операционная прибыль не равна чистой прибыли после налогов.

По одному возможному дубликату техобслуживания на бизнес добавлено специально. Повторять такой импорт вручную не нужно. Детектор сравнивает последние 30 дней (15.09–14.10) с предыдущими 30 днями (16.08–14.09). Не каждый скачок означает нарушение: сезонность и смена спроса также влияют на показатели.

manifest.json содержит контрольные суммы, количество строк и финансовые итоги. monthly_summary_reference.csv в каждой папке содержит независимые контрольные итоги по месяцам. Эти файлы не загружаются через интерфейс импорта. Генератор воспроизводим по фиксированным seed.

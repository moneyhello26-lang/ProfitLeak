# Данные для импорта в ProfitLeak

Синтетические данные кафе в Таразе за 90 дней: 04.07.2026–01.10.2026.
Валюта KZT. Файлы готовы для текущего импортера ProfitLeak.

## Загрузка

1. Создайте новый бизнес в разделе «Мой бизнес», например «Тестовое кафе».
2. Откройте «Импорт данных».
3. Выберите тип «Товары» и загрузите `products.csv` или `products.xlsx`.
   Нажмите «Проверить файл», затем «Подтвердить импорт».
4. Выберите тип «Продажи» и загрузите `sales.csv` или `sales.xlsx`.
   Проверьте файл и подтвердите импорт.
5. Выберите тип «Расходы» и загрузите `expenses.csv` или `expenses.xlsx`.
   Проверьте файл и подтвердите импорт.
6. Откройте обзор за 04.07.2026–01.10.2026.
7. В «Детекторе проблем» нажмите «Запустить анализ».

Используйте один формат для каждого типа данных: CSV или Excel. Они содержат
одинаковые записи. Повторный импорт того же набора в тот же бизнес не добавит
строки снова. Если эти данные уже есть в демо-бизнесе, выберите новый бизнес.
ZIP сначала распакуйте; сам архив импортировать не нужно.

CSV закодированы в UTF-8, разделитель - запятая. Каждый Excel-файл содержит
один лист и значения без формул. Названия колонок нужны импортеру;
перед загрузкой менять их не надо.

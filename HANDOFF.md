# ProfitLeak — финальный локальный выпуск

## Итог после завершения функций, 17 октября 2026

Готов локальный выпуск. Запуск: `./start-local.ps1`, затем
`http://127.0.0.1:5173`. Docker, облачная база и внешние AI-ключи не нужны.
Все изменения ветки `release/2026-10-17` и её удалённого аналога уже входят в
`main`: после `git fetch --all --prune` команда merge вернула `Already up to date`.
Новые функции фиксируются отдельным финальным коммитом в `main`; push не выполняется.

### Добавлено в финальном расширении

- Раздел **Деньги и платежи**, RU/ҚАЗ, desktop и адаптация к ширине 390 px.
- Счета/кассы с датой начального остатка; точные остатки в KZT.
- Поступления, списания и атомарные переводы между своими счетами.
- Платёжный календарь: ожидаемые/оплаченные/отменённые платежи; недельное и
  месячное повторение с сохранением дня месяца; защита от повторного проведения.
- Прогноз остатка по дням и предупреждение о дефиците на отдельном счёте,
  даже если общий остаток бизнеса положителен.
- Месячные бюджеты расходов и план-факт по категориям.
- Файловый обмен с банками/1С через **единый шаблон CSV/XLSX**: предпросмотр,
  ошибки по строкам, подписанное подтверждение для того же файла/счёта/бизнеса,
  защита от повторных номеров операций. Это импорт предварительно приведённых
  к шаблону выгрузок; прямые API банков и подключение к базе 1С не настроены.
- Миграция `0007`: четыре новые таблицы, без переписывания старых записей.
- Утилиты `backend/scripts/package_local.py` и `verify_local_release.py`:
  упаковка с SHA-256 и воспроизводимая проверка отдельной распакованной копии.

Правила работы, формулы и ограничения: [CASH_GUIDE.md](docs/CASH_GUIDE.md).
Продажи и расходы для расчёта прибыли отделены от факта движения денег.
Прогноз включает записанные операции и уже созданные ожидаемые платежи;
следующий экземпляр повторения создаётся после оплаты предыдущего.

### Передача

Финальный архив: **`output/ProfitLeak_local_2026-10-17-final.zip`**.
Он создаётся после финального коммита, включает `frontend/dist` и манифест с
исходным SHA коммита и SHA-256 каждого файла. ZIP, каждый хеш и наличие assets
проверяются при создании. Базы, `.env`, резервные копии, тестовые аккаунты,
`.tmp`, `.venv`, `node_modules` и Git в архив не входят.

Установка и самостоятельная проверка: [LOCAL_RELEASE.md](docs/LOCAL_RELEASE.md).
На другом компьютере нужен Python 3.11+ и первоначальная установка зависимостей.
После установки обычный запуск локален и не требует интернета.

## Запуск

```powershell
.\start-local.ps1
```

Сайт: **http://127.0.0.1:5173**, документация API: **http://127.0.0.1:5173/docs**.
FastAPI одним процессом обслуживает API и собранный React; Node/Vite при обычной
работе не запускаются. База — `backend/profitleak.db`. Миграции применяются до старта.
Ctrl+C останавливает приложение, данные сохраняются.

Локальный launcher принудительно выбирает файловую SQLite, loopback-адрес,
HTTP-cookie и отключённый внешний LLM. Старые облачные переменные `.env`
не переключают этот запуск на удалённую БД или внешнего советника. Сам `.env`
не перезаписывается. Советник работает локальными шаблонами без API-токенов.

Инструкция установки, проверки функций и восстановления: **docs/LOCAL_RELEASE.md**.
Для разработки сохранён прежний `start.ps1` с отдельными API/Vite.

## Что реализовано

- Аккаунты, вход/выход, смена пароля, сеансы и роли owner/analyst/viewer
  отдельно для каждого бизнеса; изоляция данных на сервере.
- Импорт CSV/XLSX: ошибки по строкам, предпросмотр, подтверждение, история,
  ограничения размера и защита от повторного содержимого.
- Финансовые KPI, товары, доказательства пяти правил поиска проблем,
  сохранённые анализы, статусы и заметки команды.
- Сравнение периодов, нормализация за день, прогноз и сценарии до 90 дней.
- RU/ҚАЗ, локальный советник, PDF с поддержкой казахских букв.
- Согласованное резервное копирование SQLite и восстановление в новый файл.
- Готовый интерфейс включён в архив; для обычного запуска из архива нужен
  Python с установленными зависимостями backend, а не Node или облачный аккаунт.

## Архив для передачи

`output/ProfitLeak_local_2026-10-17.zip` — снимок текущего рабочего дерева
с production-сборкой `frontend/dist`. Базовый Git-коммит — `e745629`;
архив включает последующие локальные изменения. Commit/push не выполнялись.

В архив не включены `.env`, базы, резервные копии, тестовые аккаунты/пароли,
`.tmp`, Git, `.venv` и `node_modules`. Рабочие данные передаются отдельно,
только если это нужно владельцу. Сначала распаковать в новую папку, затем
следовать `docs/LOCAL_RELEASE.md`.

Внутри архива `LOCAL_RELEASE_MANIFEST.json` содержит SHA-256 каждого файла.
Целостность ZIP, соответствие хешей и наличие assets из index.html проверены.

Облачные операции из старого отчёта отменены текущим объёмом; они не являются
неустранёнными блокерами готового локального проекта. Физический телефон и
внешняя сеть не проверялись: локальный запуск слушает только этот компьютер.

# ProfitLeak — передача готового локального проекта

## Актуальный объём: 17 октября 2026

По последнему указанию пользователя нужен **только готовый проект для компьютера,
без облачных сервисов**. Render, Neon, публичная публикация, push и проверка их
перезапуска больше не входят в этот выпуск. Новые облачные ресурсы не требуются.
История предыдущего варианта сохранена в `docs/HANDOFF_CLOUD_HISTORY.md`.

## Запуск

Для нового компьютера: `1_INSTALL.cmd`, затем `2_START.cmd`.
Полная инструкция с нуля и сценарий выступления находятся в `README.md`.

```powershell
.\start-local.ps1
```

Сайт: **http://127.0.0.1:5173**, документация API: **http://127.0.0.1:5173/docs**.
FastAPI одним процессом обслуживает API и собранный React; Node/Vite при обычной
работе не запускаются. База — `backend/profitleak.db`. Миграции применяются до старта.
Ctrl+C останавливает приложение, данные сохраняются.

Локальный launcher принудительно выбирает файловую SQLite, loopback-адрес,
HTTP-cookie и отключённый внешний LLM. Старые облачные переменные `.env`
не переключают этот запуск на удалённую БД или внешнего советника. Сам `.env`
не перезаписывается. Советник работает локальными шаблонами без API-токенов.

Инструкция установки, проверки функций и восстановления: **docs/LOCAL_RELEASE.md**.
Для разработки сохранён прежний `start.ps1` с отдельными API/Vite.

## Что реализовано

- Аккаунты, вход/выход, смена пароля, сеансы и роли owner/analyst/viewer
  отдельно для каждого бизнеса; изоляция данных на сервере.
- Импорт CSV/XLSX: ошибки по строкам, предпросмотр, подтверждение, история,
  ограничения размера и защита от повторного содержимого.
- Финансовые KPI, товары, доказательства пяти правил поиска проблем,
  сохранённые анализы, статусы и заметки команды.
- Сравнение периодов, нормализация за день, прогноз и сценарии до 90 дней.
- RU/ҚАЗ, локальный советник, PDF с поддержкой казахских букв.
- Согласованное резервное копирование SQLite и восстановление в новый файл.
- Готовый интерфейс включён в архив; для обычного запуска из архива нужен
  Python с установленными зависимостями backend, а не Node или облачный аккаунт.

## Свежие проверки этого выпуска

- **270 backend-тестов passed** на SQLite; Ruff и актуальность OpenAPI успешны.
  Остаётся одно существующее предупреждение Starlette/httpx.
- **11 frontend-тестов passed**, TypeScript и Vite production build успешны.
- Новый локальный запуск проверен на отдельной SQLite с миграциями 0001–0006.
- HTTP-проверки: два аккаунта, чужой бизнес 404 в обе стороны, CSV/XLSX,
  ошибки без записи данных, защита от дублей, точные KPI.
- Контроль импортов: выручка **38 000**, себестоимость **22 000**, валовая
  прибыль **16 000**, расходы **5 000**, операционная прибыль **11 000 ₸**.
- Демо: 270 продаж, 274 расхода, три сигнала анализа. Статус `in_progress`
  и заметка RU/ҚАЗ сохраняются при повторном анализе того же периода.
- Советник остаётся локальным даже при переданном разрешении на внешний вызов.
- В браузере локально проверены вход, ошибочный CSV с заблокированным
  подтверждением, XLSX → предпросмотр → импорт трёх продаж, CSV → импорт
  двух расходов, суммы в обзоре, RU/ҚАЗ и скачивание PDF.
- Скачанный казахский PDF: две страницы, точные KPI, обе страницы
  отрисованы и проверены визуально; буквы и таблицы отображаются корректно.
- Реальный перезапуск локального сервера: вход, импорты, суммы, заметка
  и прямые SPA-ссылки сохранены.
- SQLite backup → restore: **все строки 12 таблиц совпали**. Восстановленный
  файл затем реально запущен; повторно проверены вход, суммы и заметка.
- Рабочая база сохранена в `backups/profitleak-before-local-release-20261017.db`,
  после чего штатно обновлена с 0005 до 0006. Тестовые аккаунты и данные
  создавались только в `.tmp/local-release-20261017/`, а не в рабочей базе.
- После миграции сравнены все прежние колонки и строки 11 таблиц рабочей БД:
  данные полностью сохранены; ожидаемо изменена только версия миграции.
- Архив распакован в новую папку с пробелом в имени. Из него проверены запуск,
  миграции пустой SQLite, прямые страницы, все собранные assets, регистрация
  и отключённый внешний советник. Node при этом не запускался.

Временные журналы и тестовые PDF удалены при подготовке чистого комплекта
для выступления. Результаты предыдущего прогона перечислены выше.
Снимок интерфейса: `docs/local-release-preview.png`.
Предыдущая независимая проверка PostgreSQL 18 также прошла 266 тестов и
восстановление; PostgreSQL для текущего локального варианта не нужен.

## Архив для передачи

Актуальный комплект: `output/ProfitLeak_Presentation.zip`.
Распакованный вариант: `output/ProfitLeak_Presentation/`.
Предыдущие архивы и экспорты удалены по запросу пользователя.

Это готовое приложение для выступления: backend с миграциями и шрифтом PDF,
собранный `frontend/dist`, три демо-CSV, актуальная презентация PDF/PowerPoint,
один README с установкой и сценарием выступления, установщик и запуск.
Node, исходники интерфейса и инструменты разработки в комплекте не нужны.

В архив не включены `.env`, базы, резервные копии, тестовые аккаунты/пароли,
Git, `.venv`, `node_modules`, тесты и временные файлы. Первая установка требует
Python 3.11+ и интернета для pip. После установки приложение работает локально.
Для Windows в зависимости явно добавлен `tzdata`, необходимый для PDF с Asia/Almaty.

Комплект содержит 96 файлов. Проверены новая Python-среда 3.14 в отдельной
папке с пробелом, установка зависимостей, миграции, загрузка страниц и assets,
регистрация и демо. Суммы 5 454 000 / 2 242 500 ₸, три сигнала, сценарий
прогноза 601 125 ₸, отключённый внешний советник и казахский PDF подтверждены
HTTP-запросами. Тестовый сервер остановлен, временная установка удалена.
Целостность ZIP и побайтовое совпадение всех файлов с папкой комплекта проверены.

Рабочий проект с исходниками и его SQLite сохранён отдельно от комплекта.
Резервная копия из `.tmp/backups/` перенесена в `backups/` с проверкой SHA-256.
Commit/push при этой подготовке не выполнялись.

Облачные операции из старого отчёта отменены текущим объёмом; они не являются
неустранёнными блокерами готового локального проекта. Физический телефон и
внешняя сеть не проверялись: локальный запуск слушает только этот компьютер.

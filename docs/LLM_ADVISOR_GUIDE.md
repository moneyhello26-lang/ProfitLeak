# Экономный AI-советник: Gemini, OpenAI и запуск

ProfitLeak работает без Docker: SQLite, FastAPI и React. Для бесплатного
режима выбран Gemini 3.5 Flash-Lite. OpenAI поддерживается как резервный
провайдер. При отсутствии ключа, разрешения или доступной квоты чат использует
локальные шаблоны. Импорт, финансовые расчёты, детектор и PDF работают без LLM.

## Быстрый запуск бесплатного режима

1. Получите отдельный ключ в [Google AI Studio](https://aistudio.google.com/apikey).
   Для бесплатного режима выберите проект с Free tier и проверьте доступ модели
   в своём аккаунте. Не публикуйте ключ и не вставляйте его в чат.
2. Из корня проекта откройте `.env`. Если его ещё нет, скопируйте `.env.example`.
   Существующий файл не перезаписывайте.
3. Укажите:

```dotenv
LLM_ENABLED=true
LLM_PROVIDER=gemini
GEMINI_API_KEY=YOUR_GOOGLE_AI_STUDIO_KEY
LLM_MODEL=gemini-3.5-flash-lite
LLM_MAX_OUTPUT_TOKENS=600
LLM_HISTORY_MESSAGES=4
LLM_CACHE_TTL_SECONDS=600
```

Ключ OpenAI не подходит для Gemini. `OPENAI_API_KEY` можно оставить для резерва:
он не отправляется в Google и не используется при `LLM_PROVIDER=gemini`.

4. Перезапустите приложение в PowerShell:

```powershell
Set-Location D:\SaduakasA\ProfitLeak
.\start.ps1
```

Если PowerShell запрещает локальный скрипт:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1
```

5. Откройте http://127.0.0.1:5173/advisor. Выберите бизнес и период, запустите
   анализ в детекторе. В советнике разрешите отправку именно в Google Gemini
   и задайте вопрос. У успешного ответа будет метка Gemini с именем модели.
   Без отметки разрешения чат отвечает шаблоном.

Настройки кешируются процессом backend, поэтому изменение `.env` требует
остановки через Ctrl+C и повторного запуска. Скрипт запускает оба сервера и
применяет миграции SQLite. API-документация: http://127.0.0.1:8000/docs.

## Почему выбрана эта модель

Google описывает [Gemini 3.5 Flash-Lite](https://ai.google.dev/gemini-api/docs/models/gemini-3.5-flash-lite)
как стабильную быструю модель для задач с ограниченным бюджетом; она поддерживает
структурированные ответы. Это подходит советнику: суммы и сигналы рассчитывает
backend, модель только формулирует пояснения и предлагает проверки.

В [тарифах Google](https://ai.google.dev/gemini-api/docs/pricing) для неё указан
Free tier с бесплатными входными и выходными токенами. Это не безлимитный API:
активные лимиты и доступ зависят от аккаунта и проекта. Проверяйте их в
[AI Studio](https://aistudio.google.com/usage) и [документации о лимитах](https://ai.google.dev/gemini-api/docs/rate-limits).
Сервис не включает оплату, не оформляет подписок и не переводит ваш Google-проект
на платный тариф. Если у проекта уже включён биллинг, тариф определяет Google.

Для новых проектов Google рекомендует новые Flash-модели. Доступ к Gemini 2.5
ограничен аккаунтами, которые уже пользовались ими; поэтому устаревшие советы
выбирать 2.5 Flash-Lite могут не подойти новому ключу:
[доступность моделей](https://ai.google.dev/gemini-api/docs/deprecations).

На бесплатном тарифе Google может использовать переданные данные для улучшения
продуктов. Это отражено в разрешении внешней отправки. Используйте синтетические
данные для демонстрации; не вводите персональные сведения, банковские реквизиты
и секреты в вопрос при включённой отправке.

## Экономия токенов и запросов

- Ответ ограничен шестьюстами выходными токенами; инструкция просит краткое пояснение.
- В контекст входят KPI и до трёх главных сигналов либо один выбранный сигнал.
- Backend передаёт последние четыре сообщения истории, до 1200 символов на сообщение.
  JSON контекста компактный. Вся видимая беседа не пересылается целиком.
- Проверенные ответы кешируются на десять минут в памяти сервера, до 128 записей.
  Ключ учитывает провайдера, ключ API, модель, бизнес, период, данные, вопрос и
  передаваемую историю. Только полностью совпадающий запрос использует кеш.
  При изменении контекста или истории нужен новый ответ.
- Кеш не записывается в SQLite, очищается при перезапуске. На повторном ответе
  видна метка «Сохранённый ответ»: нового API-запроса и расхода токенов нет.
- После ошибки частоты запросов сервис делает паузу, обычно на минуту или на
  время из `Retry-After`. При ошибке кредитов OpenAI пауза по умолчанию пятнадцать
  минут. Во время паузы доступны кешированные ответы и локальные шаблоны.
- Автоматических повторов и переключения на платного провайдера нет. Пауза не
  увеличивает квоту и не заменяет исправление лимитов аккаунта.

Запросы с изменившимися данными не получают старый ответ из кеша. Отправка в
Gemini требует разрешения на этого провайдера; прежнее разрешение OpenAI не
используется. При смене провайдера, модели, бизнеса или периода отметка
в интерфейсе сбрасывается.

## Проверка без расходования токенов

```powershell
Invoke-RestMethod http://127.0.0.1:8000/api/v1/advisor/status
```

При правильной конфигурации ожидаются `provider=gemini`,
`model=gemini-3.5-flash-lite`, `enabled=true`, `ready=true`.
`ready` означает наличие флага и ключа, а не подтверждённую авторизацию.
Для окончательной проверки отправьте один вопрос с разрешением Google.
Если ответ шаблонный, проверьте указанную причину.

Для проверки кеша откройте карточку сигнала и дважды нажмите «Получить пояснение»
с разрешением внешней отправки. При неизменных данных второй ответ должен иметь
метку сохранённого. В основном чате кнопка «Новая беседа» очищает историю, после
чего одинаковый вопрос с одинаковым контекстом также может использовать кеш.

## Резервный OpenAI

Если нужен OpenAI и у аккаунта есть действующие кредиты:

```dotenv
LLM_ENABLED=true
LLM_PROVIDER=openai
OPENAI_API_KEY=YOUR_OPENAI_API_KEY
LLM_MODEL=gpt-4.1-nano
LLM_MAX_OUTPUT_TOKENS=600
LLM_HISTORY_MESSAGES=4
LLM_CACHE_TTL_SECONDS=600
```

После изменения перезапустите backend и заново разрешите отправку в OpenAI.
`gpt-4.1-nano` поддерживает Responses API и Structured Outputs:
[OpenAI Docs](https://developers.openai.com/api/docs/models/gpt-4.1-nano).
Она платная; меньшая цена модели не означает новые бесплатные токены.
При `insufficient_quota` или лимите расходов смена модели не восстанавливает
доступ: нужны кредиты или изменение соответствующего лимита проекта.
[Ошибки OpenAI](https://developers.openai.com/api/docs/guides/error-codes).

## Настройки

| Переменная | Назначение |
| --- | --- |
| `LLM_ENABLED` | Включает возможность внешнего запроса; `false` оставляет шаблоны |
| `LLM_PROVIDER` | `gemini` или `openai` |
| `GEMINI_API_KEY` | Серверный ключ Google; используется только для Gemini |
| `OPENAI_API_KEY` | Серверный ключ OpenAI; используется только для OpenAI |
| `LLM_MODEL` | ID модели; если отсутствует, Flash-Lite для Gemini или nano для OpenAI |
| `LLM_TIMEOUT_SECONDS` | Ожидание API, от 1 до 60 секунд; по умолчанию 25 |
| `LLM_MAX_OUTPUT_TOKENS` | Лимит ответа, от 200 до 4000; по умолчанию 600 |
| `LLM_HISTORY_MESSAGES` | Сообщений в контексте, от 0 до 8; по умолчанию 4 |
| `LLM_CACHE_TTL_SECONDS` | Срок кеша, от 0 до 3600 секунд; 0 отключает кеш |

Переменные окружения терминала имеют приоритет над `.env`. Проверяйте статус API
после перезапуска. Ключи не выводите в консоль. Произвольные API URL не поддержаны:
ключи отправляются только на фиксированный официальный endpoint своего провайдера.

## Факты и ограничения советника

Все суммы считает backend. LLM возвращает JSON с маркерами серверных фактов.
Backend проверяет маркеры, неизвестные ссылки и самостоятельные числа, затем
подставляет точные значения. Непроверяемый ответ заменяется шаблоном. Смысловые
гипотезы и рекомендации требуют проверки человеком.

Исходные файлы, строки платежей, их описания и имя бизнеса не отправляются.
Названия товаров/категорий могут быть в подписях агрегатов. Текущий вопрос и
ограниченная история передаются как есть после разрешения. Устаревшие сигналы
не передаются; чат предложит обновить анализ. Кандидаты в дубликаты не удаляются
автоматически, сценарная экономия не суммируется и не гарантируется.

История хранится в памяти страницы и исчезает при перезагрузке, смене бизнеса
или периода. Отдельно в памяти backend временно кешируются проверенные ответы.
Авторизация пользователей остаётся следующим этапом: текущий запуск предназначен
для локальной демонстрации на синтетических данных.

## PDF и данные

«Скачать PDF» в обзоре, товарах, детекторе, советнике и карточке сигнала создаёт
локальный отчёт без обращения в LLM. Он включает KPI, категории расходов,
прибыльность, сигналы, правила, рекомендации и исходные строки. До десяти товаров
и категорий, двадцати сигналов и шести исходных строк на сигнал; ограничения
подписаны. Анализ без запуска или после импорта отмечается явно.

Файлы для импорта находятся в `output/ProfitLeak_import_data.zip`.
Для `sales.csv` выбирайте «Продажи», для `expenses.csv` — «Расходы», для
`products.csv` — «Товары». При смене типа выбранный файл сохраняется, а
предпросмотр и токен подтверждения сбрасываются; файл нужно проверить заново.

## Ошибки

| Причина | Действие |
| --- | --- |
| `missing_key` | Добавить ключ именно выбранного провайдера, перезапустить |
| `disabled` | Включить `LLM_ENABLED`, перезапустить |
| `consent_required` | Разрешить отправку выбранному провайдеру |
| `authentication_error` | Проверить ключ, проект и доступ |
| `rate_limit` | Посмотреть активные лимиты, дождаться окончания паузы |
| `quota_exhausted` | Проверить кредиты OpenAI или лимит расходов проекта |
| `model_error` | Проверить имя модели и её доступность в аккаунте |
| `timeout` / `connection_error` | Проверить сеть и доступ к провайдеру |
| `provider_error` | Повторить позже; ошибка на стороне провайдера |
| `invalid_response` | Использовать шаблон: ответ не прошёл проверку |

При отказе LLM возвращается шаблонный ответ с причиной и временем паузы, если она
действует. Это не ошибка финансовых расчётов. API: `/advisor/status`,
`POST /advisor/chat`, `GET /reports/pdf` под префиксом `/api/v1`.

## Установка и проверка разработки

На этом компьютере зависимости установлены. На другом нужны Python 3.11+ и Node.js 22.18+:

```powershell
python -m venv backend/.venv
backend/.venv/Scripts/python.exe -m pip install -e './backend[dev]'
npm.cmd --prefix frontend ci
.\start.ps1
```

```powershell
backend/.venv/Scripts/python.exe -m pytest backend/tests -q
backend/.venv/Scripts/python.exe -m ruff check backend
backend/.venv/Scripts/python.exe backend/scripts/export_openapi.py --check
npm.cmd --prefix frontend run build
npm.cmd --prefix frontend test
```

Автоматические тесты используют заглушки API и не расходуют квоту. Они проверяют
оба протокола, согласие на провайдера, факты, изоляцию, кеш, историю и паузу квоты.
Реальный доступ к Gemini проверяется отдельно после установки вашего ключа.

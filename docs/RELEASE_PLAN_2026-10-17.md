## Обязательные условия публикации

- Backend доступен через `/api` того же HTTPS-домена, либо явно настроены
  допустимые origins и cookie; прямые URL страниц frontend открываются.
- Уникальный IMPORT_SIGNING_KEY, SESSION_COOKIE_SECURE=true для HTTPS,
  ключи LLM только на сервере; `.env` и пользовательская БД не публикуются.
- SQLite находится на постоянном диске, используется один экземпляр
  приложения; для нескольких экземпляров нужна отдельная проработка БД
  и общих лимитов запросов. Auth-лимиты сейчас хранятся в памяти процесса.
- Миграции выполнены до обслуживания трафика; `/api/v1/health` отвечает 200.
- Перезапуск сервера сохраняет данные; резервная копия восстанавливается.
- При недоступном LLM остаются локальные рекомендации.
- Первый запуск использует синтетические данные; приём реальных данных
  требует определённых правил хранения, удаления и эксплуатации.
